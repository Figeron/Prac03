1)На самом деле тут есть важный нюанс: само число 1 не превращается в 4 байта. Оно по-прежнему занимает всего 1 байт (8 бит), просто в памяти для него выделяется больше места из-за типа данных.
2)Когда мы работаем с числом 256, в его байтовом (побитовом) представлении происходит интересное явление — возникает переполнение.
3)Число 65536 требует другого (большего) набора байтов, потому что оно ровно на единицу больше максимального значения, которое можно представить с помощью заданного количества байтов.
Значение-Свойство BitConverter.IsLittleEndian в C# указывает на порядок байтов (endianness) текущей архитектуры компьютера.
При преобразовании числа в массив байтов с помощью метода BitConverter.GetBytes() порядок элементов в массиве зависит от значения IsLittleEndian.
Порядок байтов зависит от архитектуры процессора — это называется endianness.
Строка	Количество символов	Количество байтов (UTF‑8)
"ABC"	3	3 (каждый символ — 1 байт)
"Привет"	6	12 (каждый символ кириллицы — 2 байта в UTF‑8)
это разные языки поэтому они различны
На самом деле не всегда нужно снова указывать UTF-8 для обратного преобразования — это зависит от контекста
